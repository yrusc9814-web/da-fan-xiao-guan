# “今天吃什么”项目开发阶段流程总览

## 总体开发顺序

```text
资料准备
→ 基础工程
→ 数据库与接口规范
→ 视觉基线与响应式框架
→ 首页验收
→ 业务模块并行开发
→ 模块集成
→ Windows 本地部署
→ 全量测试
→ 最终验收
```

---

## 阶段 0：开发资料准备

1. 整理 PRD。
2. 整理 agent.md。
3. 放入网页端参考图。
4. 放入移动端参考图。
5. 建立 Git 仓库。
6. 确定分支和 Worktree 规则。

---

## 阶段 1：基础工程搭建

1. 创建前端工程。
2. 创建后端工程。
3. 建立前后端通信。
4. 建立统一目录结构。
5. 建立环境配置。
6. 建立日志和错误处理。
7. 建立基础测试。

---

## 阶段 2：数据库与接口底座

1. 创建 SQLite 数据库。
2. 完成 Prisma Schema。
3. 创建初始数据库迁移。
4. 建立统一 API 返回格式。
5. 建立共享 TypeScript 类型。
6. 建立健康检查接口。
7. 验证数据持久化。

---

## 阶段 3：视觉规范与响应式框架

1. 建立粉色主题变量。
2. 建立字体、圆角和阴影规范。
3. 建立桌面端侧边导航。
4. 建立移动端底部导航。
5. 建立页面布局组件。
6. 建立卡片、按钮和表单组件。
7. 建立弹窗、抽屉和状态组件。

---

## 阶段 4：首页开发与视觉验收

1. 完成网页端首页。
2. 完成移动端首页。
3. 接入首页数据接口。
4. 完成推荐菜谱区域。
5. 完成库存概览区域。
6. 完成饮食记录区域。
7. 完成统计和日历区域。
8. 对照参考图验收。

> 首页和视觉规范通过后，才能进入业务模块并行开发。

---

## 阶段 5：业务模块并行开发

1. 菜谱管理。
2. 食材管理。
3. 厨房工具。
4. 库存记录。
5. 库存推荐。
6. 剩菜消耗。

### 工作流 B：店铺与觅食

1. 店铺管理。
2. 到店分类。
3. 外卖分类。
4. 收藏店铺。
5. 搜索与筛选。
6. 店铺详情。

### 工作流 C：计划与推荐

1. 每日计划。
2. 餐次管理。
3. 随机决定。
4. 条件推荐。
5. 搭配一顿饭。
6. 推荐历史。

### 工作流 D：日记与统计

1. 饮食日记。
2. 日历筛选。
3. 食用者管理。
4. 月度统计。
5. 趋势统计。
6. 排行统计。

## 阶段 7：模块集成

建议合并顺序：

```text
菜谱与厨房
→ 店铺与觅食
→ 计划与推荐
→ 日记与统计
```

集成步骤：

1. 合并各模块分支。
2. 处理接口冲突。
3. 处理数据库变更。
4. 统一公共组件。
5. 统一样式。
6. 验证跨模块数据闭环。
7. 清除 Mock 数据。

## 并行开发原则

```text
阶段 0–4：串行
阶段 5：最多四路并行
阶段 6–12：统一集成后串行
```

并行开发期间，以下内容由总集成任务统一管理：

- Prisma Schema
- 数据库迁移
- 全局样式
- 路由
- 公共组件
- 公共类型
- package.json
- API 返回结构
